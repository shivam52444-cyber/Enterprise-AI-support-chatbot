# Order statuses and tracking

Every order has one of the following statuses.

| Status | Meaning |
|---|---|
| created | The order was placed. We are waiting for payment to be confirmed. |
| approved | Payment is confirmed. The seller has been notified. |
| invoiced | The invoice for the order was issued. |
| processing | The seller is preparing and packing the items. |
| shipped | The seller handed the package to the carrier. It is on its way. |
| delivered | The carrier marked the package as delivered. |
| canceled | The order was canceled and will not be delivered. Any payment is refunded. |
| unavailable | The seller could not supply the item, so the order cannot be fulfilled. The full amount is refunded automatically. |

## Tracking
- Orders move through the statuses in the order shown above. Not every order shows every status.
- Once an order is shipped, the tracking details are shown in My Orders.
- Tracking updates can take up to 24 hours to appear after the carrier scans the package.
- "Delivered" means the carrier marked it delivered. If you did not receive it, see the document on damaged, wrong or missing items.
- An order with status canceled or unavailable cannot be tracked.
